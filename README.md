# Trouve ton artisan - Frontend

Interface utilisateur de la plateforme "Trouve ton artisan" de la région Auvergne-Rhône-Alpes.

## Technologies

- React.js
- Bootstrap
- Sass
- Axios
- React Router DOM

## Prérequis

- Node.js v18+
- L'API doit être lancée

## Installation

1. Cloner le repo :
   git clone https://github.com/sarahbrh/trouve-ton-artisan-front.git

2. Installer les dépendances :
   npm install

3. Lancer le projet :
   npm start
